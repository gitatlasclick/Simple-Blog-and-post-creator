A modern, minimalist blog platform built with Django and Tailwind CSS that allows users to create posts and engage through comments.

✨ Features
Create Posts – Share your thoughts with a beautiful writing interface

Comment System – Engage with content through threaded comments

Responsive UI – Fully optimized for desktop and mobile devices

Clean Admin Panel – Manage posts and comments effortlessly

Real-time Feedback – Instant success messages and smooth animations

Persian Support – Full RTL support with Persian localization

🛠️ Tech Stack
Backend
Django (Python) – MVC framework

SQLite – Lightweight database (ready for production migration)

Frontend
Tailwind CSS – Utility-first styling

HTML5 + CSS3 – Semantic markup with custom animations

JavaScript – Interactive elements and smooth UX

Development Tools
Django Admin – Built-in content management

Django Forms – Secure and validated form handling
